# PR 설명 문체 검토

GitHub의 [blader/humanizer SKILL.md](https://github.com/blader/humanizer/blob/main/SKILL.md) 원문을 읽고 PR 설명에 적용했습니다. 확인한 원문의 blob SHA는 `19fc634208e8cc6ae55d4ff287152583216fd244`입니다.

## 적용한 내용

- 문장 끝을 `했습니다`, `확인했습니다`, `사용합니다` 형태로 정리했습니다.
- 추상적인 성과 설명을 줄이고 실제 함수, 입력 크기, 좌표 수, 실행 결과를 남겼습니다.
- 과한 강조와 대화용 마무리 문장을 뺐습니다.
- 코드와 명령어의 의미, 테스트 수, 경로, 실제 한계는 유지했습니다.
- 내부 승인 절차 설명은 검토 자료에 두고, PR 본문에는 구현과 검증에 필요한 내용을 담았습니다.

제목, 구현 설명, 검증 표, 제출 자료, 실행 방법, 남은 확인 사항 순서로 작성했습니다. 본문에서 31개 GoogleTest와 그 안에 포함된 4개 gMock을 더해 계산하지 않았습니다. CI가 실행된 것처럼 바꾸거나 과거 macOS 문제를 해결했다고 쓰지 않았습니다.

AI 작성 여부를 판정하는 검출기를 실행하지 않았으며, 검출 회피나 사람의 단독 작성을 보증하지 않았습니다. 이번 검토는 문장과 사실관계의 편집입니다. 별도 글쓰기 스킬 설치나 사용자 과거 글의 검색을 수행했다고 주장하지 않았습니다.

## 게시 전 확인

`week2/PR_DESCRIPTION.md`가 검토용 PR 본문입니다. 파일의 GitHub 링크는 2주차 브랜치를 Push한 뒤 열립니다. CI를 실행한 뒤에는 `남은 확인 사항`의 CI 문단을 실제 Job 결과와 Run URL로 갱신합니다. 사용자가 설명을 확인하기 전에는 원격 Push와 PR 생성을 진행하지 않습니다.
