# 최종 자체 검수 — 증거 중심 Red Team

기준일: 2026-10-23. 구현 후 요구사항과 실제 파일을 대조한 **동일 작업 세션의 자체 검토**다. 별도 사람·멘토의 독립 리뷰나 병합 승인으로 표시하지 않는다.

## A. 요구사항 완전성

원본 PDF 6–12페이지의 텍스트와 페이지 이미지를 확인했다. 6페이지의 YOLO·OCR·FastAPI 논의는 전체 프로젝트의 상황 설정이고, 이번 1차 구현 범위는 p7–12의 Git·픽셀 처리·전처리·심화 필터와 제출물이다. 후속 주차 기능을 추가하지 않았다.

공식 요구사항 25개를 추적했다. **20개 완료, 4개 미완료(R08–R11), 1개 부분완료(R25)**다. 미완료 항목은 원격 Push·PR·외부 리뷰·병합이며, R25는 저장소 생성과 PPT 작성은 완료했으나 PR이 남았다. 사용자 추가 품질 조건 Q01–Q08은 별도 표로 관리한다.

## B. 코드 정확성

자동검증 **29개 통과**. 이름별 실제 실행 결과는 `evidence/unittest.log`, 소스 해시는 `evidence/verification.json`에 있다. 파일 누락·손상·빈 입력, HSV H/S/V 경계, 밝기 임계값 직전·동일·직후, 5% 영역 경계, 분리된 연결 영역, 반전·회전·Blur·색상 변화·Normalize를 확인했다.

픽셀 분석은 BGR이다. uint8 Hue 상한을 179로 두고 양끝을 OR로 합쳤다. 밝기 threshold는 색상 마스크와 별도로 실제 사용한다. 객체 크기라고 표현한 수치는 빨간 연결 영역의 픽셀 비율이다. 일반 객체 탐지 정확도·학습 성능 수치는 만들지 않았다.

## C. 결과 신뢰성

- 별도 경로에서 전체 출력 44개를 재생성해 제출 결과와 SHA256이 전부 같았다.
- 원본 5장의 SHA256과 출처 revision을 확인했다. 모든 원본은 Food101 train 0–4이고, 단일 클래스의 작은 실습 표본임을 명시했다.
- 최종 PNG 5장은 224×224 단일 채널 uint8이다. float32 [0,1] NPY와 픽셀 대응을 검증했다.
- 결과 판정은 실사진 통과 2장·제외 3장이다. 전처리 확인용 PNG 5장과 실제 통과 NPY 2장의 용도를 구별했다.
- PPTX는 4페이지이며, 포함 이미지 **12개가 모두 비어 있지 않고 실제 원본·처리 파일과 바이트 해시가 일치**한다. `evidence/presentation_check.json` 참조.
- 구조·글꼴 지정·슬라이드 크기 검사와 PPTX 재가져오기를 통과했다. 4페이지를 각각 렌더링해 한글·코드·표·이미지·여백을 시각 검수했다. PowerPoint 앱에서 직접 열어 실행한 검증은 수행하지 않았다.

## D. Git 품질

로컬 `main`, `feature/image-processing`, origin URL과 커밋을 확인했다. init을 한 번 사용했고 동일 프로젝트를 불필요하게 clone하지 않았다. 요구사항 정의, 기능, 테스트·실제 결과, 문서, 발표 자료를 논리적으로 분리했다.

터미널 Push는 인증 부재로 실패했다. 새 비공개 저장소는 브라우저에서 생성되었지만 연결 도구 접근은 404였다. 브라우저 파일 업로드 경로도 시간 초과했으며 코드 업로드 성공으로 기록하지 않았다. 원격 저장소가 비어 있는 상태를 확인했다. PR 본문 초안과 정확한 후속 명령을 포함했다.

## E. 멘토의 재현 가능성

README 설치·기본 실행·별도 출력 경로 명령을 새 가상환경에서 수행했다. 기본 재현에 외부 데이터 다운로드가 필요 없도록 원본을 포함했다. 주요 수치의 JSON·이미지·검증 로그 위치를 명시했다. PPT는 범위·핵심 코드와 Git·실제 결과·평가와 한계 순서로 4장이다.

## F. 범위 준수

실행 코드 1개, 데이터 확보와 검증용 보조 스크립트, 표준 unittest를 사용했다. 모델 학습·객체 탐지 모델·OCR·서버·DB·웹 UI·별도 프레임워크는 추가하지 않았다. 다음 주차 개선 방향은 문서에만 있고 현재 구현으로 표시하지 않았다.

## 발견한 결함과 재확인

| 문제 | 수정 또는 처리 | 실제 재확인 |
|---|---|---|
| 초기 OpenCV 패키지 import 중 SIGBUS | 정상 동작하는 OpenCV 4.11.0.86·NumPy 2.2.6으로 고정 | 새 가상환경 설치, pip check, 전체 처리·29개 검증 성공 |
| PNG를 정규화 실수 데이터 자체로 오해할 가능성 | NPY 수치 배열과 uint8 시각화 분리 | PNG↔NPY 대응 자동검증 |
| 빨간 영역을 일반 객체 크기로 오해할 가능성 | 적용 대상·오분류·실제 제외 목록 명시 | JSON·실제 통과 파일 대응, 알려진 합성 입력·경계 검증 |
| PPT 초안 이미지가 0바이트이고 한글이 렌더링되지 않음 | 원본 이미지 바이트를 직접 포함, 한글 글꼴 등록 후 재생성 | 12개 내장 이미지 디코드·원본 해시 일치, 4장 시각 검수 |
| 초기 PPT 구조 검사만으로 누락을 잡지 못함 | 파일 구조 검사에 이미지 무결성과 렌더 확인을 함께 적용 | 수정된 PPT만 제출 폴더에 유지 |
| Git Push·PR·외부 리뷰·Merge 미완료 | 허위 완료 표시 제거, 후속 명령과 본문 제공 | README·추적표·PPT·Git 상태의 미완료 설명 일치 |

로컬 구현·실행 결과·문서에 중대한 불일치는 남기지 않았다. **외부 Git 협업 절차가 남아 있어 과제 전체의 최종 완료 판정은 보류한다.** 추가 기능 개발은 종료한다.
